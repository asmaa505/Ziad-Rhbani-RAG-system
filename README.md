# 🎹 Ziad Rahbani RAG System (سيستم استرجاع معلومات زياد رحباني)

نظام ذكاء اصطناعي يعتمد على تقنية **RAG (Retrieval-Augmented Generation)** للإجابة على الاستفسارات، تحليل النصوص، واستخراج المعلومات الخاصة بالإرث الفني والفلسفي للفنان العبقري **زياد رحباني**.

---

## 🚀 نظرة عامة على المشروع (Project Overview)
يهدف هذا المشروع إلى بناء قاعدة معرفية (Knowledge Base) شاملة ومحرك بحث ذكي قادر على فهم أسلوب زياد رحباني، مسرحياته، عباراته الساخرة، وموسيقاه، والإجابة على أسئلة المستخدمين بناءً على مصادر موثوقة ومجمعة بدقة، بدلاً من الاعتماد على الهلوسة البرمجية للنماذج اللغوية الكبيرة.

---

## 📊 هيكل البيانات ومصادرها (Data Sources & Pipeline)
يتم حالياً جمع وتصنيف الداتا لتشمل كافة الجوانب الفنية والشخصية:

*   **🎙️ اللقاءات والحوارات:** المقابلات التلفزيونية والإذاعية (المكتوبة والمفرغة نصياً).
*   **📻 البرامج الإذاعية:** تفريغ نصوص البرامج الشهيرة مثل *"العقل زينة"* و*"تابع لشي تابع"*.
*   **🎭 المسرحيات:** النصوص الكاملة للمسرحيات (*سهرية، نزل السرور، بالنسبة لبكرة شو؟، فيلم أمريكي طويل، شي فاشل، بخصوص الكرامة والشعب العنيد، لولا فسحة الأمل*).
*   **🎵 الأغاني والألبومات:** كلمات الأغاني (التي غناها أو لحنها لـ فيروز، جوزيف صقر، وغيرهم) مع الميتا-داتا الخاصة بكل ألبوم.
*   **📝 المقالات الصحفية:** الأرشيف المكتوب لزياد في الصحف والمجلات.
*   **🎬 الأفلام والوثائقيات:** الأعمال السينمائية والدراسات والبرامج الوثائقية التي تناولت مسيرته وتحليل ظاهرة زياد رحباني.

---

## 🛠️ الأدوات والتقنيات المستخدمة (Tech Stack)
*   **Language:** Python 🐍
*   **LLM Orchestration:** LangChain / LlamaIndex *(اختر المفضلة لديكِ)*
*   **Embedding Model:** `text-embedding-3-small` (OpenAI) أو نماذج تدعم اللغة العربية والعامية اللبنانية مثل `Cohere Multilingual`.
*   **Vector Database:** Qdrant / Pinecone / ChromaDB
*   **Framework/UI:** React.js / Next.js (फॉर फ्रंट-एंड واجهة المستخدم) & FastAPI (للباك-إند).
