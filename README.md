# 🎹 Ziad Rahbani RAG System

نظام ذكاء اصطناعي وتطبيق Full-Stack يعتمد على تقنية **RAG (Retrieval-Augmented Generation)** للإجابة على الاستفسارات، تحليل النصوص، واستخراج المعلومات الخاصة بالإرث الفني والفلسفي للفنان العبقري **زياد رحباني**، مزود بواجهة تفاعلية حديثة وسيرفر Backend مرن مع نظام معالجة الأخطاء والضغط العالي.

---

## 🚀 نظرة عامة على المشروع (Project Overview)
يهدف هذا المشروع إلى بناء قاعدة معرفية (Knowledge Base) شاملة ومحرك بحث ذكي قادر على فهم أسلوب زياد رحباني، مسرحياته، عباراته الساخرة، وموسيقاه، والإجابة على أسئلة المستخدمين بناءً على مصادر موثوقة ومجمعة بدقة، بدلاً من الاعتماد على الهلوسة البرمجية للنماذج اللغوية الكبيرة.

تتضمن المنظومة **Full-Stack Application** يشتمل على:
- **Backend (Python / FastAPI or Flask):** للتعامل مع قاعدة البيانات المتجهة وإدارة طلبات النماذج اللغوية وإصلاح أخطاء الخدمة.
- **Frontend (HTML5, CSS3, JavaScript):** واجهة محادثة (Chat UI) تفاعلية مستوحاة من طابع زياد رحباني الفني.

---

## 📊 هيكل البيانات ومصادرها (Data Sources & Pipeline)
جمع وتصنيف الداتا لتشمل كافة الجوانب الفنية والشخصية:

* **🎙️ اللقاءات والحوارات:** المقابلات التلفزيونية والإذاعية.
* **📻 البرامج الإذاعية:** البرامج الشهيرة مثل *"العقل زينة"* و*"تابع لشي تابع"*.
* **🎭 المسرحيات:** (*سهرية، نزل السرور، بالنسبة لبكرة شو؟، فيلم أمريكي طويل، شي فاشل، بخصوص الكرامة والشعب العنيد، لولا فسحة الأمل*).
* **🎵 الأغاني والألبومات:** الأغاني (التي غناها أو لحنها لـ فيروز، جوزيف صقر، وغيرهم) مع الميتا-داتا الخاصة بكل ألبوم.
* **📝 المقالات الصحفية:** الأرشيف المكتوب لزياد في الصحف والمجلات.
* **🎬 الأفلام والوثائقيات:** الأعمال السينمائية والدراسات والبرامج الوثائقية التي تناولت مسيرته وتحليل ظاهرة زياد رحباني.

## 🛠️ بنية النظام الهندسية (System Architecture)

ينقسم المشروع إلى 4 مراحل رئيسية:
1. **تجهيز وتجزئة النصوص (Chunking):** قراءة البيانات الفنية المصنفة في صيغة JSON وتجزئتها لقطع نصية جاهزة للفهرسة.
2. **توليد وتخزين المتجهات (Embedding & Vector DB):** تحويل النصوص إلى متجهات رقمية باستخدام نموذج `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2` متعدد اللغات، وتخزينها في قاعدة بيانات متجهة مستمرة **ChromaDB**.
3. **الـ Backend ومعالجة الطلبات (Resilient Backend API):**
   - استقبال أسئلة المستخدمين عبر API.
   - استرجاع النصوص ذات الصلة بالسؤال من ChromaDB.
   - إرسال البيانات المجمعة في Prompt مخصص لنموذج **Gemini 3.5 Flash**.
   - إدماج **Auto-Retry & Exponential Backoff** لمعالجة الضغط العالي وأخطاء السيرفر (503 Service Unavailable).
4. **الـ Frontend & UI Deployment:**
   - تصميم واجهة شات متجاوبة بأسلوب مظلم مميز (Dark Mode).
   - عرض الروابط والمراجع الخارجية والوسائط الأرشيفية.
   - رفع الواجهة عبر **GitHub Pages** واستخدام Root Redirect لتوفير وصول مباشر للـ Frontend.
